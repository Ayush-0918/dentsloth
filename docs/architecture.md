# DentSloth Architecture

> Full mermaid diagram to be added in Phase 6.

## Components
- **FastAPI backend** – Python, Pydantic v2, pymongo
- **React + Vite frontend** – TypeScript, bilingual i18n
- **Gemma via Ollama** – local vision + NLP
- **TabPFN** – resale price prediction
- **MongoDB Atlas** – listings, wishlists, Vector Search
- **Render** – web service + static site + cron
